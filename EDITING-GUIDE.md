# MuSDT Website Editing Guide

All editable project information is stored in `site-config.js`.

To update the website, edit values in that file and upload the changed files to GitHub. The main fields are:

- `project`: name, symbol, decimals, contract address, network, standard, total supply, logo
- `hero`: homepage label, title, highlighted title, description
- `mission`: project description, revenue purpose, social-support purpose, transparency statement
- `team`: project owner, CEO, deputy director, and board member information
- `support`: email, phone, Twitter, Facebook, and Telegram
- `documents`: whitepaper, audit, explorer, and revenue policy links/status
- `roadmap`: numbered development phases

The HTML and CSS should only need editing when the visual layout or page sections change.
